# FormApp

A simple form application.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/FormApp.git
   cd FormApp
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the app:
   ```bash
   npm start
   ```
